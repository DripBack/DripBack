## 🧠 Tech-Stack-Philosophy

**Multi-Model-AI** statt Single-Vendor-Lock-In.

Wir wählen pro Task das passende LLM:
- **Klassifikation / Routing** → lokales `qwen2.5:7b`/`14b` (kostenneutral, On-Premise)
- **Komplexes Reasoning** → Claude Sonnet (Cloud, DSGVO-konform via Frankfurt)
- **Generierung** → GPT-4 oder lokale Mixtral-Modelle
- **Embeddings** → `nomic-embed-text` lokal

Alles wahlweise **on-premise** (eigene Server) oder **DACH-Cloud** (Hetzner Frankfurt).
Sensible Daten verlassen Deutschland nicht.
